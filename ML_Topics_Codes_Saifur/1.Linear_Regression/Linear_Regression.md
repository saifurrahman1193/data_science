# Types of Linear Regression 
1. Simple Linear Regression
2. Multiple Linear Regression
3. Multivariate Linear Regression


# Difference between 
#### Simple Linear Regression, Multiple Linear Regression, and Multivariate Linear Regression



| Feature                             | Simple Linear Regression                                                  | Multiple Linear Regression                                                                | Multivariate Linear Regression                                                                            |
| ----------------------------------- | ------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| **Definition**                      | A model with one independent variable (X) and one dependent variable (Y). | A model with multiple independent variables (X1, X2, ...) but one dependent variable (Y). | A model with multiple independent variables (X1, X2, ...) and multiple dependent variables (Y1, Y2, ...). |
| **Equation**                        | Y = b0 + b1X1                                                             | Y = b0 + b1X1 + b2X2 + ... + bnXn                                                         | Y1 = b0 + b1X1 + b2X2 + ... + bnXn <br> Y2 = c0 + c1X1 + c2X2 + ... + cnXn                                |
| **Number of Independent Variables** | 1                                                                         | More than 1                                                                               | More than 1                                                                                               |
| **Number of Dependent Variables**   | 1                                                                         | 1                                                                                         | More than 1                                                                                               |
| **Example**                         | Predicting house price based on area.                                     | Predicting house price based on area, number of bedrooms, and age.                        | Predicting both house price and rental value based on area, number of bedrooms, and age.                  |
| **Usage**                           | Basic trend analysis                                                      | Complex relationships with multiple factors                                               | Complex systems where multiple outcomes need to be predicted                                              |
