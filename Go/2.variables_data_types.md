# 🧮 Go Integer Types

## ✅ Signed Integers
| Type   | Size   | Range                     |
|--------|--------|---------------------------|
| int8   | 8-bit  | -128 to 127               |
| int16  | 16-bit | -32,768 to 32,767         |
| int32  | 32-bit | -2.14 billion to 2.14 billion |
| int64  | 64-bit | ±9.2 quintillion          |
| int    | 32 or 64-bit (depends on system) | Platform-dependent |

## ✅ Unsigned Integers
| Type    | Size   | Range                      |
|---------|--------|----------------------------|
| uint8   | 8-bit  | 0 to 255                   |
| uint16  | 16-bit | 0 to 65,535                |
| uint32  | 32-bit | 0 to 4.29 billion          |
| uint64  | 64-bit | 0 to 18.4 quintillion      |
| uint    | 32 or 64-bit (depends on system) | Platform-dependent |

## ✅ Type Aliases
| Alias  | Actual Type | Description           |
|--------|-------------|-----------------------|
| byte   | uint8       | Typically used for binary data |
| rune   | int32       | Represents a Unicode code point |

## 🧪 Example

```go
package main

import "fmt"

func main() {
    var a int8 = -100
    var b uint16 = 65535
    var c rune = '🌟'
    var d byte = 255

    fmt.Println(a, b, c, d) // Output: -100 65535 127775 255
}
